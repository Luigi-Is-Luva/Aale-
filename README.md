# CUNY Course Canvas

Pastel front-end prototype for a smart syllabus and study guide app.

## Pages

- `index.html` - syllabus input with a Google Calendar-style output for classes, exams, and assignments
- `study.html` - notes input with generated flashcards and study tips

## Files

- `styles.css` - shared pastel design system
- `script.js` - demo interactions for buttons and flashcards
