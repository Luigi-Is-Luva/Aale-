# CUNY Course Canvas

CUNY Course Canvas is an MTA-inspired React frontend for turning syllabi into a semester-wide course map.

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://127.0.0.1:5173/`.

## Files

- `index.html` - Vite entry page
- `mta-main.jsx` - React mount file
- `mta/CourseCanvas.jsx` - MTA-style frontend
- `mta/parse-route.ts` - Gemini API route reference
